# Sistem Data Pegawai

## 1. Tujuan
Program ini dibuat untuk menampilkan data pegawai yang terdiri dari nama, jabatan, dan gaji pokok. Program menggunakan HTML, CSS, dan JavaScript untuk menghitung gaji bersih setiap pegawai serta menampilkan pegawai dengan gaji bersih tertinggi.

## 2. Cara Menjalankan
1. Siapkan file `index.html` dan `style.css` dalam satu folder.
2. Pastikan kode HTML sudah terhubung dengan file CSS.
3. Buka file `index.html` menggunakan browser seperti Google Chrome atau Microsoft Edge.
4. Data pegawai akan ditampilkan dalam bentuk tabel secara otomatis.
5. Periksa bagian bawah tabel untuk melihat informasi pegawai dengan gaji bersih tertinggi.

## 3. Hasil Uji
Berdasarkan pengujian program, hasil yang diharapkan adalah:
- Data empat pegawai berhasil ditampilkan dalam tabel HTML.
- Tunjangan sebesar 20% diberikan kepada pegawai dengan jabatan Manager.
- Pajak sebesar 10% dihitung untuk semua pegawai berdasarkan gaji pokok.
- Gaji bersih dihitung dari gaji pokok ditambah tunjangan, kemudian dikurangi pajak.
- Program berhasil menampilkan pegawai dengan gaji bersih tertinggi, yaitu Citra dengan jabatan Manager dan gaji bersih Rp13.200.000.
- Tampilan halaman dapat menyesuaikan layar kecil dengan bantuan CSS.

## 4. Batasan
- Data pegawai masih ditulis langsung di dalam kode JavaScript.
- Program belum memiliki fitur untuk menambah, mengubah, atau menghapus data pegawai melalui halaman web.
- Data tidak disimpan ke database sehingga perubahan data tidak tersimpan secara permanen.
- Perhitungan pajak dan tunjangan hanya mengikuti ketentuan pada soal.
- Program hanya menampilkan data dan hasil perhitungan, belum memiliki fitur login atau pengelolaan data pegawai.

## Kesimpulan
Program Sistem Data Pegawai dapat menampilkan data pegawai, menghitung gaji bersih berdasarkan jabatan dan pajak, serta menentukan pegawai dengan gaji bersih tertinggi menggunakan perulangan dan percabangan JavaScript.
