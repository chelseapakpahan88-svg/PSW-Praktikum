# README - Profil Mahasiswa IT Del

## 1. Tujuan
Tujuan dari pembuatan website ini adalah untuk membuat halaman profil pribadi mahasiswa menggunakan HTML dan CSS. Website ini menampilkan foto profil, nama lengkap, NIM, program studi, dan deskripsi singkat. HTML digunakan untuk membuat struktur halaman, sedangkan CSS digunakan untuk mengatur tampilan, warna, ukuran teks, dan tata letak agar lebih menarik dan mudah dibaca.

## 2. Cara Menjalankan
1. Siapkan file `index.html` dan `style.css` di dalam folder yang sama.
2. Simpan foto profil dengan nama `foto.jpg` di folder tersebut.
3. Buka file `index.html` menggunakan browser, seperti Google Chrome atau Microsoft Edge.
4. Periksa apakah halaman profil, foto, dan seluruh informasi mahasiswa sudah tampil dengan benar.

## 3. Hasil Uji
Berdasarkan pengujian yang dilakukan melalui browser, halaman profil dapat menampilkan judul “Profil Mahasiswa IT Del”, foto profil, nama Chelsea S Pakpahan, NIM 41426018, program studi DIV TRPL, dan deskripsi singkat. CSS juga digunakan untuk memberikan latar belakang abu-abu kebiruan, warna merah muda pada header dan footer, kotak profil berwarna putih, serta foto berbentuk lingkaran dengan bayangan halus. Media query ditambahkan agar tampilan dapat menyesuaikan layar HP yang berukuran kecil. Hasil akhir perlu diperiksa langsung melalui browser untuk memastikan seluruh bagian tampil sesuai harapan.

## 4. Batasan
Website ini masih berupa halaman profil sederhana dan belum memiliki fitur interaktif. Informasi mahasiswa masih ditulis langsung di dalam kode HTML sehingga perubahan data harus dilakukan secara manual. Foto profil juga harus tersedia di folder yang sama dan menggunakan nama file yang sesuai. Selain itu, website belum menggunakan database atau sistem login, sehingga data profil belum dapat dikelola secara otomatis.
