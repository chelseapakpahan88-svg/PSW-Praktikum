1. Cara menjalakannya
Buka folder proyek di VS Code, lalu jalankan file index.html menggunakan Live Server website akan terbuka di browser dan dapat diperiksa tampilannya.

2. Tujuan
Praktikum ini bertujuan untuk memahami penggunaan Flexbox dalam mengatur navigasi dan card agar tampilan website lebih rapi serta dapat menyesuaikan ukuran layar.

3. Penjelasan Perubahan
Perubahan dilakukan pada file style.css, yaitu menambahkan Flexbox pada navigasi dan kumpulan card, mengatur jarak serta ukuran elemen, dan menggunakan variabel CSS untuk warna dan jarak. Selain itu, ditambahkan pengaturan agar teks panjang tidak mudah keluar dari card.

4. Hasil Uji
Berdasarkan pengujian, perubahan CSS berhasil diterapkan dengan status kode 200. Warna dan tampilan elemen menyesuaikan pengaturan CSS,
sedangkan navigasi dan card menggunakan Flexbox untuk mengatur posisi serta ukuran elemen.

5. Batasan
Pengujian masih perlu dilengkapi pada ukuran layar berbeda, seperti 360px dan 1200px, serta pada kondisi judul panjang dan penggunaan keyboard.
