1. Pengertian Git
Git adalah sistem pengontrol versi (Version Control System) yang digunakan untuk mencatat dan mengelola perubahan pada file atau kode program selama proses pengembangan perangkat lunak.

Dengan Git, kita dapat mengetahui perubahan yang dilakukan, melihat riwayat pekerjaan, dan kembali ke versi sebelumnya jika terjadi kesalahan. Git banyak digunakan oleh programmer untuk mengembangkan proyek secara individu maupun bersama tim.
2. Fungsi Git
Berikut beberapa fungsi Git yang penting untuk diketahui.
- Mencatat perubahan: Menyimpan riwayat perubahan pada file proyek.
- Mengembalikan versi sebelumnya: Membantu memulihkan kode ketika terjadi kesalahan.
- Membuat branch: Memungkinkan kita mengerjakan fitur baru tanpa mengganggu kode utama.
- Menggabungkan perubahan: Menggabungkan hasil pekerjaan dari beberapa branch.
- Mendukung kerja sama: Memudahkan beberapa programmer mengerjakan proyek yang sama.

3. Perbedaan Git dan GitHub
Git adalah perangkat lunak untuk mencatat, mengelola, dan melacak perubahan kode di komputer

GitHub adalah platform online untuk menyimpan repositori Git, berbagi kode, dan bekerja sama dengan orang lain.

Contohnya, kita menggunakan Git untuk mencatat perubahan pada website yang sedang dibuat. Kemudian, kita menggunakan GitHub untuk mengunggah dan menyimpan proyek tersebut secara online.

4. Istilah Penting dalam Git
Istilah	Penjelasan sederhana
Repository (Repo)	Tempat menyimpan file proyek beserta riwayat perubahannya.
Working Directory	Folder tempat kita mengerjakan dan mengubah file proyek.
Staging Area	Tempat menyiapkan perubahan yang akan disimpan dalam commit.
Commit	Catatan atau rekaman perubahan yang disimpan di Git.
Branch	Cabang pekerjaan untuk mengembangkan fitur atau melakukan perbaikan.
Merge	Proses menggabungkan perubahan dari satu branch ke branch lain.
Clone	Mengunduh salinan repositori Git ke komputer.
Push	Mengirim commit dari komputer ke repositori jarak jauh, misalnya GitHub.
Pull	Mengambil dan menggabungkan perubahan dari repositori jarak jauh.
Fetch	Mengambil informasi perubahan dari repositori jarak jauh tanpa langsung menggabungkannya.
Diff	Menampilkan perbedaan antara dua versi file atau kode.
Conflict	Kondisi ketika perubahan yang berbeda bertabrakan dan perlu diselesaikan.

5. Perintah Git yang Sering Digunakan
Berikut beberapa perintah dasar Git beserta fungsinya.
Perintah	Fungsi
git init	Membuat repositori Git baru di folder proyek.
git status	Memeriksa kondisi file dan perubahan yang ada.
git add .	Menyiapkan semua perubahan yang terdeteksi di folder saat ini.
git commit -m "pesan"	Menyimpan perubahan yang sudah disiapkan sebagai commit.
git log	Melihat riwayat commit.
git branch	Melihat daftar branch.
git switch nama-branch	Berpindah ke branch lain.
git switch -c nama-branch	Membuat branch baru sekaligus berpindah ke branch tersebut.
git diff	Melihat perubahan kode yang belum masuk staging area.
git push	Mengirim commit ke repositori jarak jauh.
git pull	Mengambil dan menggabungkan perubahan terbaru dari repositori jarak jauh.
git clone URL	Menyalin repositori dari alamat yang diberikan.
