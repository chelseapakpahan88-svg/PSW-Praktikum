Refleksi dari fungsi HTML, CSS, JavaScript dan Git Bash

1. HTML (HyperText Markup Language)
adalah bahasa yang digunakan untuk membuat struktur sebuah halaman website. HTML bisa digunakan untuk membuat judul, paragraf, tombol dan bagian bagian lainnya pada sebuah website.

2. CSS (Cascading Style Sheets)
digunakan untuk mengatur tampilan website. Misalnya mengatur warna, ukuran tulisan, jenis font, jarak, posisi, dan desain halaman agar terlihat lebih menarik.

3. JavaScript (js)
adalah bahasa pemograman yang digunakan ntuk membuat website menjadi lebih interaktif dan bisa melakukan suatu aksi. Contohnya seperti tombol yang bisa ditekan, munculnya pesan, perhitungan otomatis, atau perubahan tampilan pada website.

4. Git Bash
aplikasi yang digunakan untuk menjalankan perintah Git melalui terminal. Git sendiri berguna untuk menyimpan dan mengatur perubahan pada kode, sehingga kita bisa melihat riwayat perubahan dan mengelola proyek coding dengan lebih mudah.
