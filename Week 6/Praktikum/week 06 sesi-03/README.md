1. Cara Menjalankan
Buka folder proyek di VS Code, kemudian jalankan index.html menggunakan Live Server buka website melalui browser untuk melihat hasilnya.

2. Tujuan Praktikum
Mempelajari cara membuat website responsif menggunakan CSS, gambar fleksibel, ukuran teks dinamis, container query, dan pengaturan preferensi pengguna.

3. Perubahan yang Dilakukan
- Menambahkan gambar dengan atribut responsif.
- Mengatur tata letak menggunakan Grid, Flexbox, dan media query.
- Mencoba clamp untuk ukuran teks.
- Menambahkan container query dan fitur aksesibilitas.

4. Hasil Pengujian
Struktur HTML telah diperiksa menggunakan HTML Validator tampilan responsif, pemuatan gambar, dan fitur lainnya perlu diuji kembali melalui browser untuk memastikan semuanya berjalan dengan baik.

5. Batasan
Beberapa pengujian, seperti zoom, reduced motion, dan perubahan lebar container, masih perlu dilengkapi gambar dengan resolusi 320px dan 640px juga perlu dibuat sebagai file yang berbeda.
