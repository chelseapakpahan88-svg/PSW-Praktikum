1. Cara Menjalankan
Buka folder proyek di VS Code, kemudian jalankan index.html menggunakan Live Server website akan terbuka di browser dan dapat diuji melalui DevTools.

2. Tujuan
Praktikum ini bertujuan untuk memahami penerapan CSS mobile-first dan media query agar tampilan website dapat menyesuaikan ukuran layar, baik pada perangkat kecil maupun besar.

3. Penjelasan Perubahan
Perubahan dilakukan pada file style.css dengan menggunakan CSS Grid untuk mengatur kartu kegiatan dalam satu kolom pada layar kecil dan dua kolom pada layar yang lebih lebar media query dengan breakpoint 48rem ditambahkan untuk mengubah susunan kartu navigasi juga menggunakan Flexbox dengan flex-wrap agar dapat menyesuaikan ruang yang tersedia. Selain itu, ditambahkan pengaturan min-width: 0 pada kartu untuk membantu mencegah elemen melebar secara berlebihan.

4. Hasil Uji
Folder bukti berisi tangkapan layar hasil validasi HTML dan CSS, termasuk bukti validasi yang berhasil dan satu hasil validasi yang menunjukkan error kode CSS juga telah memuat media query pada breakpoint 48rem pengujian tampilan pada viewport 320px, 768px, 1200px, serta zoom 200% masih perlu dilakukan dan didokumentasikan agar sesuai dengan seluruh ketentuan modul.

5. Batasan
Pengujian responsivitas dan kondisi khusus, seperti judul panjang, zoom 200%, serta navigasi menggunakan keyboard, masih perlu dilengkapi. Bukti pengujian sebelum dan sesudah perbaikan juga perlu ditambahkan.
