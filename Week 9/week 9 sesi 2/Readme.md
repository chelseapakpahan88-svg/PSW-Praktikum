1. Eksperimen String dan Number

Pada percobaan ini, saya mempelajari perbedaan tipe data String dan Number menggunakan kode const teks = "2";. Nilai "2" termasuk String karena menggunakan tanda petik. Ketika teks ditambah dengan angka 1, hasilnya menjadi 21 karena JavaScript menggabungkan teks, bukan menjumlahkannya. Namun, ketika menggunakan Number(teks) + 1, hasilnya menjadi 3 karena nilai teks sudah diubah menjadi angka. Saya juga mencoba typeof untuk mengetahui tipe data dan Number("abc") yang menghasilkan NaN karena teks tersebut tidak bisa diubah menjadi angka. Dari percobaan ini, saya memahami bahwa String dan Number memiliki fungsi yang berbeda. Oleh karena itu, tipe data harus diperhatikan agar tidak terjadi kesalahan saat melakukan perhitungan.

2. Eksperimen Jumlah 1 sampai 5 dan Harga Tetap Tiket

Pada percobaan ini, saya membuat program untuk memeriksa jumlah tiket yang boleh dibeli, yaitu minimal 1 dan maksimal 5. Program menggunakan kondisi if untuk memeriksa apakah jumlah bukan bilangan bulat, kurang dari 1, atau lebih dari 5. Ketiga kondisi tersebut menggunakan operator || yang berarti ATAU. Jika salah satu kondisi terpenuhi, program akan menampilkan pesan bahwa jumlah tidak valid. Jika jumlah sesuai aturan, program akan menghitung total harga dengan mengalikan jumlah tiket dengan Rp10.000. Saya mencoba beberapa nilai seperti 0, 1, 5, 6, 1.5, dan "abc". Hasilnya, hanya angka 1 sampai 5 yang diterima. Dari percobaan ini, saya memahami bahwa input harus diperiksa terlebih dahulu sebelum digunakan dalam perhitungan agar program tidak menerima data yang salah.
