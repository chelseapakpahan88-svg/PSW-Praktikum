1. Cara Menjalankan
Buka folder proyek di VS Code, kemudian jalankan index.html menggunakan Live Server website akan terbuka di browser dan dapat diuji melalui DevTools.

2. Tujuan Pengerjaan
Tujuan pengerjaan praktikum ini adalah mengintegrasikan beberapa halaman dengan navigasi dan gaya konsisten.; Menggunakan branch serta merge tanpa menghilangkan perubahan

3. Hasil uji
Pengujian dilakukan untuk memastikan website dapat berjalan dan perubahan CSS berfungsi dengan baik Pertama ada halaman beranda, dilakukan pemeriksaan terhadap tampilan judul, menu navigasi, kartu kegiatan, dan gambar menu kegiatan dan daftar diperiksa untuk memastikan tautannya mengarah ke halaman yang sesuai selain itu, animasi gambar diuji dengan mengarahkan kursor ke gambar kegiatan untuk melihat apakah gambar membesar dan menampilkan bayangan tampilan kartu serta formulir pendaftaran juga diperiksa untuk memastikan perubahan warna dan validasi formulir berjalan sesuai dengan kode yang digunakan. Tidak ada masalah ketika melakukan uji viewport 320px, 768px, dan 1280px serta zoom 200%

4. Batasan
Website ini masih memiliki beberapa batasan. Animasi gambar hanya memberikan efek visual ketika kursor diarahkan ke gambar dan belum membuat gambar dapat diklik untuk membuka halaman detail kegiatan.
